# Resume Instructions

A clean, pre-generated resume PDF has already been generated at:
`assets/resume/Mihir_Raval_Resume.pdf`

### How to Update or Replace with your Custom PDF:
1. Export your custom resume from Google Docs, Word, or Canva as a PDF.
2. Name the file: `Mihir_Raval_Resume.pdf`
3. Replace the file inside this directory:
   `assets/resume/Mihir_Raval_Resume.pdf`
4. The portfolio's "Download Resume" buttons across the header, hero, and footer will automatically serve your new file immediately without changing any code.
